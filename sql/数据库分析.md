## 课程表(study_lesson)和文章表(study_article)
的关系和功能结合：
-- 文章表中有 lesson_id 字段，与课程表关联

`lesson_id` bigint(20) DEFAULT NULL COMMENT '所属课程ID'
2. 使用场景：
- 课程相关文章：
- 课程介绍文章
- 课程大纲文章
- 课程教案文章
- 课程补充资料
- 独立知识文章：
- 行业资讯
- 技术分享
- 学习方法
- 经验总结

- 展示方式：
    课程详情页
    ├── 课程基本信息 (study_lesson)
    ├── 课程章节 (study_lesson_chapter)
    │   ├── 视频/音频资源 (study_lesson_resource)
    │   └── 章节相关文章 (study_article, lesson_id关联)
    └── 课程相关文章列表 (study_article, lesson_id关联)
    

- 业务流程：
- 创建课程时：
    1. 先创建课程基本信息(study_lesson)
    - 创建课程章节(study_lesson_chapter)
    - 上传课程资源(study_lesson_resource)
    - 编写课程相关文章(study_article)，关联lesson_id

- 浏览课程时：
    - 用户访问课程详情
    - 显示课程基本信息
    - 展示课程章节和资源
    - 展示相关文章列表

- 文章管理：
    - 创建文章时可以选择是否关联课程
    - 关联课程的文章会在课程详情页展示
    3. 独立文章在知识库板块展示

2. 统计功能：
-- 课程表中的统计字段
`view_count` bigint(20) DEFAULT '0' COMMENT '浏览量',
`like_count` bigint(20) DEFAULT '0' COMMENT '点赞数',
`collect_count` bigint(20) DEFAULT '0' COMMENT '收藏数',

-- 文章表中的统计字段
`view_count` bigint(20) DEFAULT '0' COMMENT '阅读量',
`like_count` bigint(20) DEFAULT '0' COMMENT '点赞数',
`collect_count` bigint(20) DEFAULT '0' COMMENT '收藏数',

课程和文章都有独立的统计数据，可以分别统计：
- 课程的受欢迎程度（购买数、收藏数等）
- 文章的阅读情况（阅读量、点赞数等）

这种设计可以让课程和文章既能独立运作，又能紧密结合，提供完整的学习体验：
- 课程提供系统化的学习内容和资源
- 文章提供补充的知识点和延伸阅读
- 两者相互关联，形成完整的知识体系

## 课程表、课程章节表、课程资源表、文章表的联系
让我详细解释这四个表的关系和设计思路：

### 1. 表之间的关系图
study_lesson (课程表)
    │
    ├──── study_lesson_chapter (课程章节表)
    │          │
    │          └──── study_lesson_resource (课程资源表)
    │
    └──── study_article (文章表)

### 2. 具体关联关系
- 课程 -> 章节：一对多关系
    -- study_lesson_chapter表中的关联字段
    `lesson_id` bigint(20) NOT NULL COMMENT '课程ID'
    - 一个课程可以包含多个章节
- 每个章节必须属于一个课程
- 通过lesson_id进行关联
- 
2. 章节 -> 资源：一对多关系
-- study_lesson_resource表中的关联字段
`lesson_id` bigint(20) NOT NULL COMMENT '课程ID',
`chapter_id` bigint(20) DEFAULT NULL COMMENT '章节ID'
- 一个章节可以包含多个资源
- 资源必须属于一个课程，可以选择性属于某个章节
- 同时保存lesson_id和chapter_id便于查询和管理

- 课程 -> 文章：一对多关系（可选）
    -- study_article表中的关联字段
    `lesson_id` bigint(20) DEFAULT NULL COMMENT '所属课程ID'
    - 一个课程可以关联多篇文章
- 文章可以选择是否关联课程
- 通过lesson_id进行关联

### 3. 业务场景示例
- 创建新课程：
    1. 创建课程基本信息
       └── INSERT INTO study_lesson
    2. 创建课程章节
       └── INSERT INTO study_lesson_chapter
    3. 上传课程资源
       └── INSERT INTO study_lesson_resource
    4. 关联课程文章
       └── INSERT INTO study_article

- 查询课程详情：
    -- 1. 查询课程基本信息
    SELECT * FROM study_lesson WHERE lesson_id = ?
    
    -- 2. 查询课程章节
    SELECT * FROM study_lesson_chapter 
    WHERE lesson_id = ? 
    ORDER BY sort
    
    -- 3. 查询章节资源
    SELECT * FROM study_lesson_resource 
    WHERE lesson_id = ? 
    
    ORDER BY chapter_id, sort
    
    -- 4. 查询相关文章
    
    SELECT * FROM study_article 
    
    WHERE lesson_id = ? 
    
    ORDER BY sort
    

- 学习课程内容：
    
```
    课程页面
    ├── 课程信息 (study_lesson)
    │   ├── 课程标题
    │   ├── 课程描述
    │   └── 课程标签
    │
    ├── 章节列表 (study_lesson_chapter)
    │   ├── 章节1
    │   │   ├── 视频1 (study_lesson_resource)
    │   │   ├── 音频1 (study_lesson_resource)
    │   │   └── 教案文章 (study_article)
    │   │
    │   └── 章节2
    │       ├── 视频2 (study_lesson_resource)
    │       └── 练习文章 (study_article)
    │
    └── 相关资料
        └── 扩展阅读文章 (study_article)
    
```

### 4. 数据完整性维护

- 删除课程时：
    -- 需要级联删除或处理：
    1. 相关章节 (study_lesson_chapter)
    2. 章节资源 (study_lesson_resource)
    3. 关联文章 (study_article) - 可以选择解除关联而不删除
    
- 删除章节时：
    -- 需要处理：
    1. 章节下的资源 (study_lesson_resource)
    2. 更新其他章节的排序
    

这种设计的优点：
- 结构清晰，层次分明
- 支持灵活的课程内容组织
- 便于内容管理和展示
- 支持多种类型的学习资源
- 文章可以独立存在，也可以作为课程补充材料
