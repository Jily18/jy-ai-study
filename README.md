## 平台简介

RuoYi 是一个基于 SpringBoot 的快速开发平台，适用于各种 Web 应用程序开发，包括：

- 网站管理后台
- 会员中心系统
- CMS 内容管理系统
- CRM 客户关系管理
- OA 办公自动化

主要特点：
- 前后端代码封装完善，易于上手
- 支持移动端访问
- 持续更新维护
- 完全开源，免费使用

相关版本：
- [RuoYi-Vue](https://gitee.com/y_project/RuoYi-Vue) - 前后端分离版本
- [RuoYi-Cloud](https://gitee.com/y_project/RuoYi-Cloud) - 微服务版本

特别感谢：
- [hplus](https://gitee.com/hplus_admin/hplus) 后台主题 UI 框架

## 主要功能

### 系统管理
- 用户管理：系统用户配置
- 部门管理：组织机构树形管理
- 岗位管理：用户职务配置
- 菜单管理：系统菜单与权限配置
- 角色管理：权限分配与数据范围划分

### 系统工具
- 字典管理：常用数据维护
- 参数管理：系统参数配置
- 代码生成：前后端代码自动生成
- 系统接口：自动生成API文档
- 定时任务：任务调度与日志

### 系统监控
- 操作日志：系统操作记录
- 登录日志：用户登录记录
- 在线用户：实时用户监控
- 服务监控：系统资源监控
- 缓存监控：缓存管理
- 连接池监控：数据库性能分析

### 其他功能
- 通知公告：信息发布
- 在线构建器：表单生成
